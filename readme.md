### Progressly – Social Progress Tracking Platform

**MongoDB • Express.js • React • Node.js • Redis • JWT • Docker**

* Building a full-stack social progress-tracking platform that enables users to create custom metrics, track daily activities, and share their progress with others.
* Implementing JWT-based authentication using HttpOnly cookies and bcrypt for secure password hashing.
* Designing flexible MongoDB data models that allow users to define customizable trackable entities such as study hours, problem-solving counts, workout frequency, and personal goals.
* Developing interactive graphs and visualizations to represent progress, streaks, frequency, and historical trends while using Redis for caching frequently accessed data.
* Building RESTful APIs and a responsive React interface while using Docker to containerize and manage application services.

**Run Server**

```bash
# From the project root
cd server
npm install
npm run dev
```
